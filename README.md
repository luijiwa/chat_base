Статус реализации задания
Полностью реализовано (F1–F4)
F1 — Интерфейс чата:
- Экран чата отображает от 5 до 10 сообщений с идентификаторами, авторами и текстом.
- Присутствуют поле ввода и кнопка отправки сообщения.
- Пустые сообщения отклоняются (их нельзя отправить).
- Приложение успешно запускается на выбранной платформе.
F2 — Отправка сообщений:
- После отправки новые сообщения сразу появляются в списке.
- Во время отправки отображаются статусы pending (ожидает отправки), sent (отправлено) и failed (ошибка отправки).
- Локальный асинхронный метод с задержкой имитирует сетевой запрос.
- Во время отправки приложение остаётся доступным для дальнейшей работы.
F3 — Обработка ошибок и повторная отправка:
- Повторная отправка после ошибки выполняется вручную с использованием того же clientId (идентификатора сообщения).
- Во время повторной отправки кнопка соответствующего сообщения блокируется.
- После успешной повторной отправки статус той же записи меняется на sent.
- Дублирующиеся сообщения в списке не появляются.
F4 — Архитектура и проверка:
- Логика отправки сообщений вынесена из виджетов и реализована с использованием паттерна BLoC.
- Интерфейс (UI) и бизнес-логика (BLoC/repository) разделены.
- Ручная проверка сценария «ошибка → повторная отправка → успех» проходит успешно.
- Реализована валидация пустого поля ввода.
- Изменение статусов работает корректно.
- Дублирующиеся сообщения не создаются.

- Изначально кодовая база представляла собой пакет для создания прокручиваемого списка сообщений чата. В неё были внесены изменения для соответствия требованиям технического задания.
- Проект успешно компилируется и запускается в симуляторах Android и iOS.
